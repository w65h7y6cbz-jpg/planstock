# Logos des locaux

Déposez ici le logo de chaque local, puis écrivez son nom de fichier dans
Réglages → Ce local → Logo (par exemple `optimium.png`).

- Formats acceptés : `.png`, `.jpg`, `.svg`, `.webp`.
- Une image carrée rend le mieux : elle est affichée en 34 px dans la barre du
  haut, 92 px sur l'écran d'accueil et 72 px sur l'écran de choix du local.
- Sans fichier, PlanStock dessine un pictogramme dans la couleur du local.

Ces fichiers sont servis par PlanStock lui-même : rien n'est chargé depuis
Internet.
